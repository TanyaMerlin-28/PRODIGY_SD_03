# PRODIGY_SD_03

📞 Contact Management System

ProDigy Infotech – Software Development Internship (Task 03)

A simple Python-based Contact Management System that allows users to add, view, edit, and delete contacts with persistent file storage, developed as part of ProDigy Infotech Task-03.

📌 Project Overview

The Contact Management System is a simple Python-based application that allows users to store, manage, and organize contact information efficiently.
Users can add new contacts, view existing contacts, edit contact details, and delete contacts when needed.
The application uses file handling to ensure that contact data is saved permanently and available even after restarting the program.

✨ Features

➕ Add new contacts (Name, Phone Number, Email)

📄 View all saved contacts

✏ Edit existing contact details

🗑 Delete contacts

💾 Persistent storage using a text file

📋 Simple menu-driven interface

🧑‍💻 Beginner-friendly Python implementation

🛠 Technologies Used

Programming Language: Python

▶ How to Run the Program

Clone the repository

git clone https://github.com/Tanya Merlin-28/contact-management-system.git


Navigate to the project folder

cd contact-management-system


Run the program

python contact_management.py

🧾 How It Works

The program displays a menu with multiple options.

User selects an operation:

Add Contact

View Contacts

Edit Contact

Delete Contact

Contact data is saved in contacts.txt for permanent storage.

The program continues running until the user chooses to exit.
